# Quickstart: 敏感词过滤增强（Phase 2-4）

## 前置条件

- Phase 1（审计日志）已完成并部署
- 管理员可访问管理后台

---

## 1. 启用输出侧过滤

1. 进入管理后台 → 系统设置 → 敏感词设置
2. 开启「输出侧过滤」开关
3. 保存设置

**验证**：发送一个会触发 LLM 返回敏感词的请求，在审计日志页面查看 direction=output 的记录。

---

## 2. 配置分级敏感词规则

### 2.1 添加单条规则

1. 进入管理后台 → 系统设置 → 敏感词设置
2. 在规则管理区域点击「添加规则」
3. 填写：关键词、级别（block/warn/log）、类别、用户组
4. 保存

**验证**：
- block 级别：发送包含该词的请求，应被拒绝
- warn 级别：请求通过，但审计日志有记录
- log 级别：请求通过，审计日志有记录

### 2.2 批量导入规则

1. 准备 CSV 文件：
   ```csv
   word,level,category,group
   敏感词1,block,politics,
   敏感词2,warn,custom,vip
   ```
2. 或准备 TXT 文件（每行一个词）：
   ```
   敏感词1
   敏感词2
   ```
3. 进入管理后台 → 敏感词设置 → 点击「导入」
4. 选择文件和格式，上传

**验证**：导入后在规则列表中查看新规则。

### 2.3 导出规则

1. 进入管理后台 → 敏感词设置 → 点击「导出」
2. 下载 CSV 文件

---

## 3. 配置 PII 检测

1. 进入管理后台 → 系统设置 → 敏感词设置 → PII 检测
2. 开启 PII 检测总开关
3. 为每种 PII 类型配置：
   - 手机号：开启 + 选择策略（mask/block/log）
   - 身份证：开启 + 选择策略
   - 银行卡：开启 + 选择策略
   - 邮箱：开启 + 选择策略
   - IPv4：开启 + 选择策略
4. 保存设置

**验证**：
- mask 策略：发送包含手机号的请求，上游 LLM 收到的是脱敏后的号码（如 138****1234）
- block 策略：发送包含身份证号的请求，应被拒绝
- log 策略：请求通过，审计日志有 PII 检测记录

---

## 4. 查看审计日志

1. 进入管理后台 → 审计日志
2. 按方向（输入/输出）、级别（block/warn/log）筛选
3. 查看详细的命中词、处理动作、内容预览

---

## 5. 向后兼容

现有扁平敏感词列表（旧版配置）自动作为 block 级别规则的后备，无需迁移。新旧规则合并使用。

---

## 常见问题

**Q: 流式响应下能阻断敏感词吗？**
A: 不能。流式模式下 chunk 已逐步发送给客户端，只能记录审计日志。非流式响应可以阻断。

**Q: PII 正则误报怎么办？**
A: 管理员可以禁用特定 PII 类型，或调整策略为 log（仅记录不处理）。

**Q: 导入 CSV 报错怎么办？**
A: 检查 CSV 格式是否正确（必须有 word,level,category,group 列头），word 不能为空。
